# Aetheria

A stylized 3D open-world action RPG for Android, built with Godot 4.

## Project status

Foundation phase: third-person controller, touch controls, a small explorable prototype region, and Android build automation.

## Requirements

- Godot 4.4.1
- Android export templates for APK export

## Build

Pushes to `main` trigger the Android debug APK workflow. The APK is published as a GitHub Actions artifact.

This is an original fantasy world and IP. It takes broad inspiration from open-world adventure design without using Zelda characters, names, maps, music, art, or other protected assets.
